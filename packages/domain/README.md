# Zugfolge domain kernel

This dependency-free JavaScript kernel is the executable reference for the first
Walking Skeleton (`FEAT-0001`). It proves the constitutional invariants before
they are ported into the JVM 21 game server:

- half-open, exclusive infrastructure occupations;
- atomic rejection on a capacity conflict;
- deterministic planning-window order without payment input;
- immutable balanced postings in integer minor units;
- deterministic replay and sequence-gap detection.

The production authority remains the planned Kotlin game server. Keeping this
small reference executable gives contracts and AI-generated implementations a
fast, language-neutral oracle during the foundation phase.
