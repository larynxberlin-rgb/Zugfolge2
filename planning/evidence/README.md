# Milestone evidence

Copy `../EVIDENCE_TEMPLATE.yaml` to `MS-nnn.yaml` only when a milestone enters
verification. Replace every placeholder with repository links, immutable
digests, or an explicit `not-applicable` plus rationale.

An evidence file proves an exit; it is not a progress diary. Do not store:

- credentials or internal access details;
- personal data or private reviewer contact data;
- raw licensed provider payloads;
- hidden reasoning or chat transcripts;
- unsigned claims that a check passed.

The milestone status may become `completed` only in the same reviewed change
that finalizes its evidence file.
