and their confusingly similar variants are intended project identifiers.

No software or documentation license in this repository grants permission to
use these identifiers in a way that implies endorsement, an official game
world, or affiliation with the project owner.

Descriptive references, truthful compatibility statements, repository forks,
and notices required by an applicable software or data license remain
unaffected. Forks should use a distinct product name and logo unless the project
owner has granted written permission.

This policy is provisional. Domain registration and DPMA/EUIPO similarity
searches must be completed before public launch. It is not a statement that a
registered trademark already exists.
